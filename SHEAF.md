## 1. Преамбула: Від Контекстного Допуску до Пучка Істин

У складних розподілених системах (`SWARM-0.1`, `SCOPED_ADMISSION-0.1`) діє непорушний принцип:
> **«Істина всесвітня, застосовність місцева» (WARRANT.md §7).**

Кожен організм або агент отримує знання в межах свого локального контексту $U$ (бюджет кроків, припущення, доменні аксіоми). Проте, коли виникає потреба об'єднати знання декількох агентів у глобальну теорему $s \in \mathcal{F}(\bigcup U_i)$, наївна конкатенація призводить до парадоксів та прихованих колізій.

У вищій геометрії та топології точним математичним апаратом локально-глобального узгодження є **теорія пучків (Sheaf Theory)** на топологічному просторі.

`SHEAF-0.1` переносить теорію пучків на категорію епістемічних контекстів $\mathbf{Ctx}$.

## 2. Математична Архітектура: Топос Контекстів та Пучок $\mathcal{F}$

```
                  [ Топологія відкритих контекстів U_i ]
                   U_1: {SKI, LinearLogic | Budget 120}
                   U_2: {LinearLogic, ProofNets | Budget 150}
                   U_3: {SKI, ProofNets | Budget 180}
                                    |
                                    v
                  [ Локальні перерізи (Local Sections) ]
                   s_1 in F(U_1), s_2 in F(U_2), s_3 in F(U_3)
                                    |
                                    v
                     { Обчислення перетинів U_i ^ U_j }
                                    |
                                    v
                     [ Функторіальні звуження (res_{V, U}) ]
                   res(s_1)|_{U_12}  =?=  res(s_2)|_{U_12}
                                    |
                   +----------------+----------------+
                   |                                 |
           (Всі збігаються)                (Хоча б один розбігся)
                   |                                 |
                   v                                 v
         delta s_{ij} == 0                 delta s_{ij} != 0
        [ Čech dim H^1 = 0 ]              [ Čech dim H^1 > 0 ]
                   |                                 |
                   v                                 v
     { Синтез глобального перерізу }      { Епістемічна обструкція }
      s in F(U_1 \/ U_2 \/ U_3)           Fail-Closed відхилення:
     Статус: GLUED_GLOBAL                Локальні істини несумісні!
```

### 2.1. Топос Контекстів $\mathbf{Ctx}$
Контекст $U = \langle \text{name}, \text{domains}, \text{budget}, \text{invariants} \rangle$ є відкритим набором умов.
- **Спеціалізація (Poset $V \le U$):** $V$ є підконтекстом $U$ ($V \subseteq U$), якщо домени $V$ входять у $U$, ліміт бюджету $V \le U$, а інваріанти $V$ зберігають усі інваріанти $U$.
- **Перетин $U \cap V$:** Спільна область застосування $\text{domains}(U) \cap \text{domains}(V)$ з мінімальним бюджетом $\min(\text{budget}_U, \text{budget}_V)$. Якщо спільні домени порожні, перетин є порожнім множиною $\emptyset$.

### 2.2. Передпучок (Presheaf $\mathcal{F}$)
Контраваріантний функтор $\mathcal{F}: \mathbf{Ctx}^{\text{op}} \to \mathbf{Set}$:
1. Кожному контексту $U$ зіставляє набір верифікованих тверджень $\mathcal{F}(U)$.
2. Кожній спеціалізації $V \le U$ зіставляє відображення звуження $\text{res}_{V, U}: \mathcal{F}(U) \to \mathcal{F}(V)$, що задовольняє аксіомам категорного функтора:
   - $\text{res}_{U, U} = \text{id}_{\mathcal{F}(U)}$ (Тотожність).
   - $\text{res}_{W, V} \circ \text{res}_{V, U} = \text{res}_{W, U}$ для всіх $W \le V \le U$ (Композиція).

### 2.3. Аксіома Пучка (Склейка та Спуск / Sheaf Descent)
Для будь-якого відкритого покриття $\mathcal{U} = \{U_i\}$ контексту $U = \bigcup U_i$:
- **Локальність:** Якщо два глобальні докази $s, t \in \mathcal{F}(U)$ збігаються на всіх картах покриття ($\text{res}_{U_i, U}(s) = \text{res}_{U_i, U}(t)$ для всіх $i$), то $s = t$.
- **Склейка:** Якщо родина локальних доказів $\{s_i \in \mathcal{F}(U_i)\}$ узгоджена на всіх парних перетинах $U_{ij} = U_i \cap U_j$:
  $$\text{res}_{U_{ij}, U_i}(s_i) = \text{res}_{U_{ij}, U_j}(s_j) \quad \forall i, j$$
  тоді існує **єдиний глобальний доказ** $s \in \mathcal{F}(U)$, звуження якого на кожну карту $U_i$ дає вихідний $s_i$.

### 2.4. Когомології Чеха як Міра Епістемічної Перешкоди ($H^1(\mathcal{U}, \mathcal{F})$)
Якщо локальні докази дають різний результат на перетині $U_{ij}$:
$$(\delta s)_{ij} = \text{res}_{U_{ij}, U_i}(s_i) \ominus \text{res}_{U_{ij}, U_j}(s_j)$$
Коланцюг $\delta s$ утворює 1-коцикл Чеха.
- Якщо $[\delta s] = 0 \in H^1(\mathcal{U}, \mathcal{F})$: розбіжності відсутні або тривіально зведені калібрувальним перетворенням. Склейка дозволена (`is_gluing_admissible = True`).
- Якщо $[\delta s] \ne 0 \in H^1(\mathcal{U}, \mathcal{F})$: виявлено топологічну перешкоду до глобального консенсусу (несумісність вихідних припущень). Система **відхиляє глобальне твердження** без аварії (`fail-closed`).

## 3. Нормативні Інваріанти SHEAF-0.1

* **`SH1` (Topological Poset Specialization):**  
  Спеціалізація контекстів є рефлексивною, транзитивною та антисиметричною. Перетин $U \cap V$ строго монотонно звужує бюджети та об'єднує інваріанти.
* **`SH2` (Strict Functoriality of Restrictions):**  
  Відображення звуження $\text{res}_{V, U}$ зберігає нормальну форму комбінатора і задовольняє тотожність та асоціативність композиції. Звуження за межі підконтексту або з перевищенням ліміту кроків негайно викидає виключення `ValueError`.
* **`SH3` (Unique Global Section Synthesis):**  
  За умови нульового дефекту Чеха ($H^1 = 0$) ядро гарантовано синтезує єдиний глобальний переріз зі статусом `GLUED_GLOBAL`, що успадковує об'єднані домени та максимальний верифікований бюджет.
* **`SH4` (Fail-Closed Cohomology Gate):**  
  Будь-який нетривіальний коцикл $\delta s_{ij} \ne 0$ на відкритому перетині $U_i \cap U_j$ повністю блокує склейку (`is_gluing_admissible = False`).
* **`SH5` (Covering Completeness):**  
  Спроба перевірки спуску на покритті, де для хоча б однієї карти відсутній локальний переріз, негайно повертає відхилення без обчислення коциклів.
* **`SH6` (ISO 32000 Simplicial Polyglot & Tamper Defense):**  
  Сертифікат спуску пучка компілюється як двошаровий ISO 32000 PDF із векторною графікою нерва покриття $\mathcal{N}(\mathcal{U})$, аудитом коциклів та автономним Python-аудитором (`python3 sheaf.pdf --audit`). Будь-яка модифікація байтів маніфесту блокується через хеш `MANIFEST_HASH`.
