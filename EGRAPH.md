> **Статус:** ПРИЙНЯТО ТА РЕАЛІЗОВАНО (EGRAPH-0.1) у Рушії #28: [egraph_kernel.py](egraph_kernel.py).

Вирішення проблеми фазового порядку правил (Phase Ordering Problem), неруйнівне насичення рівностей (Equality Saturation), ліс сертифікованих обґрунтувань (Proof Forest Justifications) та карантин епістемічно спростованих алелей.

## 1. Преамбула: Межі Деструктивного Переписування

У попередніх рушіях Project Black-Heart редукція комбінаторів здійснювалася за стандартною односпрямованою моделлю:
1. `glyph.py`: Ліво-зовнішня нормалізація термів під контролем ліміту газу ATP.
2. `metamorphosis.py`: AST-зіпери та заміна підвиразів $t[u \to v]$.
3. `warrant_kernel.py`: Символьна редукція гіпотез Черча-Россера ($E \to A$).

Ця модель має три фундаментальні обмеження:
- **Проблема фазового порядку (Phase Ordering):** Застосування правила $\tau_1$ перед $\tau_2$ може знищити синтаксичний патерн, необхідний для глибокої оптимізації, заблокувавши організм у локальному оптимумі.
- **Цикли та розбіжність:** Симетричні чи комутативні правила ($a \leftrightarrow b$) призводять до нескінченних циклів або вимагають штучних евристичних обмежень.
- **Евристичні здогадки замість доведень:** Звичайне переписування дає лише результат «зійшлося / не зійшлося», не генеруючи компактного детермінованого ланцюга покрокових математичних еквівалентностей.

`EGRAPH-0.1` розв'язує ці проблеми шляхом запровадження **Епістемічних E-Графів (Equality Saturation)**.

## 2. Архітектура Епістемічного E-Графа

```
       +-----------------------------------------------------------------------------+
       |               ВХІДНІ КОМБІНАТОРНІ ТЕРМИ (S (K (S I)) (K I) x, S K K x)     |
       +-----------------------------------------------------------------------------+
                                              |
                                              v
       +-----------------------------------------------------------------------------+
       |             1. E-GRAPH КОРІНЬ: ХЕШ-КОНСИНГ ТА UNION-FIND                    |
       |  EClass (Класи Еквівалентності) <---> ENode (Операторні Вузли: @, Comb, Var)|
       |  Disjoint-Set Forest з компресією шляхів та ранжуванням                     |
       +-----------------------------------------------------------------------------+
                                              |
                                              v
       +-----------------------------------------------------------------------------+
       |             2. НЕРУЙНІВНЕ НАСИЧЕННЯ (Equality Saturation Loop)              |
       |  LHS -> RHS додає ребро еквівалентності: union(c_lhs, c_rhs, rule_name)     |
       |  Жоден проміжний стан НЕ знищується! Класи розростаються конгруентно        |
       +-----------------------------------------------------------------------------+
                                              |
                                              v
       +-----------------------------------------------------------------------------+
       |             3. ВІДНОВЛЕННЯ КОНГРУЕНТНОСТІ (Rebuild / Congruence Closure)    |
       |  Якщо a == a' та b == b', то (a @ b) == (a' @ b') об'єднуються автоматично  |
       +-----------------------------------------------------------------------------+
                         /                                           \
                        v                                             v
       +----------------------------------+         +----------------------------------+
       | 4. ЛІС СЕРТИФІКОВАНИХ ОБҐРУНТУВАНЬ|         | 5. ДИНАМІЧНА ЕКСТРАКЦІЯ ОПТИМУМУ |
       |  Пошук найкоротшого шляху в графі|         |  Беллман-Форд релаксація вартості|
       |  Формування покрокового ланцюга: |         |  Вилучення найменшого за ATP AST |
       |  t1 = u1 = u2 ... = t2           |         |  Ігнорування циклічних петель    |
       +----------------------------------+         +----------------------------------+
                                              \     /
                                               v   v
       +-----------------------------------------------------------------------------+
       |            6. КАРАНТИН СПРОСТОВАНИХ НАДГРОБКІВ (Tombstone Quarantine)       |
       |  Звірка з EpistemicTombstoneRegistry: отруєні класи позначаються як TAINTED |
       |  Гарантія: Оптимальний код ніколи не містить спростованих алелей            |
       +-----------------------------------------------------------------------------+
```

## 3. Нормативні Інваріанти EGRAPH-0.1

### Інваріант EG1: Congruence Invariant (Конгруентність Застосування)
Якщо два класи $c_1$ та $c_2$ об'єднані ($c_1 \equiv c_2$), то для будь-яких батьківських вузлів:
$$\forall (c_1 @ r), (c_2 @ r) \implies (c_1 @ r) \equiv (c_2 @ r)$$
$$\forall (l @ c_1), (l @ c_2) \implies (l @ c_1) \equiv (l @ c_2)$$
Процедура `rebuild()` гарантує відновлення цієї властивості за поліноміальний час.

### Інваріант EG2: Canonical ENode Uniqueness (Унікальність Вузлів)
У межах одного E-Графа не може існувати двох ідентичних канонічних вузлів `ENode(op, children)` у різних класах. Хеш-консинг відображає канонічний вузол рівно в один унікальний EClass ID.

### Інваріант EG3: Sound Proof Forest Connectivity (Повнота Обґрунтування)
Будь-яке об'єднання `union(id1, id2, justification)` фіксує неорієнтоване ребро в лісі доведень з міткою правила або конгруентності. Для будь-якої пари $t_1 \equiv t_2$ процедура `explain_equivalence(t1, t2)` зобов'язана генерувати неперервний крок-за-кроком ланцюг тотожностей.

### Інваріант EG4: Acyclic Optimal Extraction (Ациклічність Екстракції)
Функція динамічного програмування `extract_optimal(class_id)` гарантує вилучення скінченного ациклічного комбінаторного дерева (AST), вартість якого є глобально мінімальною серед усіх представлених у класі альтернатив.

### Інваріант EG5: Fail-Closed Tombstone Quarantine (Ізоляція Надгробків)
Якщо будь-який вузол у класі $C$ відповідає спростованому патерну з `EpistemicTombstoneRegistry` (Інваріант I3/I4), клас маркується як `is_tainted = True`. Екстрактор зобов'язаний обходити отруєні класи, захищаючи активні геноми від токсичних мутацій.

### Інваріант EG6: ISO 32000 §7.5.6 Unbroken Append-Only Physicality
Стан E-Графа, сертифікати доведень та маніфест `EGRAPH_MANIFEST` серіалізуються у векторний PDF зі збереженням префіксу попередніх байтів (`after.startswith(before) == True`).

## 4. Алгоритм Еквівалентнісного Насичення

```python
def saturate(rules, max_iterations, fuel_atp):
    for iteration in 1..max_iterations:
        matches = []
        for rule in rules:
            for eclass in egraph.classes:
                matches += match(rule.lhs, eclass)
        
        for (lhs_class, rhs_pattern, subst, rule_name) in matches:
            rhs_class = instantiate(rhs_pattern, subst)
            egraph.union(lhs_class, rhs_class, justification=rule_name)
            
        egraph.rebuild()
        if no_new_unions or fuel_exhausted:
            break
```
