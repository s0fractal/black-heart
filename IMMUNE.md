## 1. Преамбула: Еволюція без імунітету приречена на вимирання

У попередніх рушіях Project Black-Heart було створено:
1. **Самовідтворювані квін-організми (Рушії #22, #23):** Здатні читати власні байти, модифікувати геном через AST-зіпери та нарощувати тіло за стандартом ISO 32000 §7.5.6.
2. **Епістемічне ядро свідчень (Рушій #24, WARRANT-0.2):** Строга класифікація свідчень на 5 ґатунків (∅, G, A, E, C) та три-стадійний вердикт (`pass`, `fail`, `unverified`).
3. **Контрольоване забування (Рушій #25, CONTROLLED-FORGETTING-0.1):** Інваріанти I1–I8, міра покриття негативного простору $\mu(C)$ та надгробні стели.

Проте досі між цими підсистемами існував критичний розрив:
- **Амнезія мутацій:** Якщо в поколінні $g$ мутація $\tau: P \to P'$ була відкинута через розбіжність семантики, покоління $g+1$ або $g+2$ могло знову запропонувати те саме хибне переписування і спалити ATP газ на заздалегідь приречений експеримент.
- **Енергетична кара без винагороди:** Знайдений контрприклад просто фіксувався в лозі, не повертаючи організму енергію, витрачену на виявлення тупика.
- **Ізоляція невдач:** Досвід загибелі чи регресу одного організму не рятував сусідні організми від повторення тієї самої катастрофи.

`EPISTEMIC-IMMUNE-0.1` перетворює пасивний реєстр надгробків на **активну адаптивну імунну систему**.

## 3. П'ять компонентів імунної системи

### 3.1. ResurrectionDefense: Передпольотний імунний бар'єр (Invariant I3)
Перед тим, як витратити хоча б одну одиницю ATP на тестові редукції кандидата $\tau$, система викликає:
```python
is_ok, reason = ResurrectionDefense.preflight_check(registry, candidate_rule, target_digest)
```
Якщо правило чи його хеш присутні в реєстрі надгробків у статусі `RETIRED` (і не мають підписаного `ReAdoptionRecord`), мутація блокується миттєво.  
*Результат:* Організм ніколи не витрачає енергію на спростовані чи відкликані шляхи пошуку.

### 3.2. Counterexample Metabolism: Конвертація помилок у паливо
Коли кандидат зазнає невдачі на фікстурі $y$, імунна система не просто відкидає його:
1. Синтезує `CounterexampleWitness(input_expr=y, expected=..., actual=..., atp=...)`.
2. Випускає підписане ребро ґатунку C: `EdgeClaim(Polarity.REFUTE)`.
3. Розраховує міру негативного простору $\mu(C) \in [0.0, 1.0]$.
4. Нараховує метаболічну премію в резерв організму:
   $$\text{Bounty} = \text{base\_atp} + \lfloor 200 \times \mu(C) \rfloor$$
5. Реєструє надгробок з обов'язковою декларацією втрати (Інваріант I4).

### 3.3. Hypothesis Elevation ($E \to A$): Автоматичне перетворення досвіду на закони
Емпіричні гіпотези, які пережили серію поколінь без контрприкладів, перевіряються автоматичним верифікатором збіжності Черча-Россера (`promote_empirical_to_axiomatic`):
- Якщо консистентність для символьних змінних $x, y, z$ доведена, гіпотеза ґатунку $E$ стає **Аксіоматичною Тотожністю ґатунку $A$**.
- Старий емпіричний запис ретирується зі статусом `SUPERSEDED` та вказівкою `replacement_id`.
- Нова аксіома стає частиною постійного генетичного ядра організму і може бути винесена на голосування Агори.

### 3.4. Horizontal Swarm Inoculation: Горизонтальне щеплення рою
При взаємодії двох організмів (схрещування, P2P-синхронізація чи діалог) відбувається взаємне щеплення:
- Організм $A$ передає свій `EpistemicTombstoneRegistry` організму $B$.
- Організм $B$ перевіряє Ed25519-підписи в домені `retirement-sig-v1:`.
- Валідні надгробки поглинаються імунною пам'яттю $B$.  
*Результат:* Організм $B$ набуває імунітету до помилок $A$, не витративши жодної власної краплі ATP.

### 3.5. Starvation Autophagy: Голодна автофагія та самовідновлення
Якщо резерв палива організму падає нижче критичного рівня ($\text{ATP} \le \theta_{\text{starve}}$):
1. Організм переходить у статус `STARVATION`.
2. Імунна система виявляє нежиттєво важливі (`vital == False`) або надмірно роздуті хромосоми.
3. Кандидати архівуються в історичний субстрат (`mode=ARCHIVED`), їхні вирази згортаються.
4. За рахунок утилізації баласту організм вивільняє екстрене паливо:
   $$\Delta\text{ATP} = 40 + \text{tree\_size}(c) \times 4$$
5. Організм повертається до гомеостазу (`HOMEOSTASIS`).

## 4. Термодинамічний баланс енергії

Повний енергетичний баланс організму на кроці еволюції $g \to g+1$:

$$\text{ATP}_{g+1} = \text{ATP}_g - \text{Cost}_{\text{metabolism}}(\text{Genome}) + \sum \text{Bounty}(\mu(C)) + \Delta\text{ATP}_{\text{autophagy}}$$

Імунна система робить епістемічне дослідження прибутковим: **чим глибші та загальніші контрприклади знаходить організм, тим більше енергії він має для репродукції.**

## 5. Візуальний векторний HUD у форматі ISO 32000

За стандартом ISO 32000 §7.5.6 імунний стан організму відбивається у формі інкрементного оновлення документа:
- **Колірна індикація статусу:**
  - Зелений смарагд (`#33D966`): `HOMEOSTASIS`
  - Бурштин (`#E6A626`): `METABOLIC_STRESS`
  - Багряний рубін (`#F24040`): `STARVATION`
- **Шкала палива ATP (Dynamic Gauge Bar):** Візуальний рівень наповненості метаболічного резерву.
- **Лічильник щеплень (Swarm Inoculations):** Кількість поглинених зовнішніх надгробків рою.
- **Індикатор негативного простору:** Сумарний об'єм підрізаного дерева AST ($\sum \mu(C)$).
- **Автономний аудитор:** Вбудований Python-раннер:
  ```bash
  python3 organism.pdf
  ```
  який trustless-перевіряє всі підписи та цілісність імунної пам'яті.
