# x8000 — Документ, представлення та CLI

**Чернетка контракту поверху, не свідчення завершеності реалізації.**
Карта коду: `8fed8bb834e37c190bc512ebc74f9440e4a3e8fa`. Під час цієї редакції прочитано названі
інтерфейси/документи; повний набір тестів поверху не запускався.
[Індекс поверхів](ADDRESS-INDEX.md). Роадмап, межі й терміни поки живуть тут;
адреси `x8001`–`x8003` зарезервовані, окремі файли не створено.

## 1. Предмет і межа

Спосіб звернення до документа й читання його даних. Цей поверх не встановлює властивостей сусідніх шарів самим фактом
їх використання. Статус draft означає запропонований опис, а не дозвіл на
реалізацію всіх пунктів роадмапу.

## 2. Контракт

Для LI-взаємодії хостовий CLI читає PDF як дані підтримуваного профілю. `inspect` описує отримане, `add-claim` формує пропозицію; зміна стану належить x9. Вбудований код вхідного PDF не є перевіряльником, якому цей шлях делегує довіру.

Рендероване представлення й семантичний маніфест мають бути розрізнені. LI-3 має data-only наступника; його читабельність не вимагає виконуваного поліглота. Адреса файла рахується з фактичних байтів, а не з видимого тексту сторінки.

## 4. Обмеження

Підтриманий маніфест не дорівнює перевірці повної відповідності PDF стандарту. Ізольований запуск довіреного раннера не є sandbox для довільного PDF. Позначки ISO чи self-audit у старих описах не успадковуються цією картою.

## 5. Роадмап і критерії приймання

- [ ] Описати фактичні прапорці команд із вкладеного --help та область кожного поля результату.
- [ ] При додаванні профілю PDF перевірити xref, неоднозначні маніфести та відсутність виконання вводу.
- [ ] Відділити відтворювані представлення/кеші від підписаних першоджерел; втрата кешу не повинна вимагати перепідписування історії.

## 6. Терміни та походження

| Термін | Локальне значення й межа |
| --- | --- |
| CLI | Інтерфейс довіреного локального інструмента; документ не отримує автономного процесу через наявність команди. |
| Кеш | Відтворюване представлення; заявки, рішення та квитанції не оголошуються кешем автоматично. |

Генеалогія тут обмежена посиланнями на репозиторій вище. Академічне
першоджерело та історичне авторство, де потрібні, мають бути перевірені
окремо; схожість назв не встановлює перенесення теореми.
