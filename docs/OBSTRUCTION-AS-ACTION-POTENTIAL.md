## 2. Анатомія поточної системи: Когомологія як гальмо ($H^1 \neq 0 \implies \text{Veto}$)

У поточній реалізації пучка знань ([SHEAF.md](../SHEAF.md)) та федеративної агори ([AGORA.md](../AGORA.md) §7) когомології Чеха застосовуються виключно як **захисний бар'єр (негативний контроль)**:

1. Нехай маємо відкрите покриття простору контекстів $\mathcal{U} = \{U_i\}_{i \in I}$.
2. Кожна палата або локальний контекст $U_i$ пропонує свій узгоджений переріз $s_i \in \mathcal{F}(U_i)$.
3. На перетинах контекстів $U_{ij} = U_i \cap U_j$ обчислюється 1-коцикл Чеха:
   $$\delta c_{ij} = s_j|_{U_{ij}} - s_i|_{U_{ij}}$$
4. **Поточна поведінка (знак «мінус»):**
   * Якщо для всіх $i, j$ виконується $s_i|_{U_{ij}} = s_j|_{U_{ij}}$, то $\dim H^1(\mathcal{U}, \mathcal{F}) = 0$. Перерізи гармонійно склеюються в глобальну істину $\implies$ статус `RATIFIED_GLOBAL`.
   * Якщо ж знайдено хоча б одну неузгодженість на перетині ($\delta c_{ij} \neq 0$), виникає когомологічна обструкція:
     $$[c] \in H^1(\mathcal{U}, \mathcal{F}) \neq 0$$
   * Система видає безумовне вето:
     $$\text{Status} \leftarrow \texttt{REJECTED\_COHOMOLOGICAL\_FRACTURE}$$

У такій моделі обструкція працює як аварійне гальмо поїзда: рух зупиняється, файл залишається заблокованим, система засинає в очікуванні зовнішнього втручання.

## 3. Інверсія знаку: Обструкція як Потенціал Дії ($H^1 \neq 0 \implies \text{Gradient}$)

У фізиці та нейробіології різниця потенціалів $\Delta V = V_A - V_B \neq 0$ не зупиняє процеси, а є **єдиною причиною виникнення струму**:
$$\vec{E} = -\nabla V$$
У живій клітині мембранний потенціал спокою тримає напругу. Коли баланс порушується, виникає **потенціал дії (action potential)** — нервовий імпульс, хвиля деполяризації, яка рухає організм.

### Перевертання знаку в теорії пучків
> **Обструкція склеювання — це не заборона існування. Це точна адреса наступної дії.**

Ненульовий 1-коцикл Чеха $c \in Z^1(\mathcal{U}, \mathcal{F})$ володіє унікальними властивостями, які роблять його ідеальним рушієм:

1. **Гранична локалізованість:** Коцикл вказує не взагалі на «помилку десь у системі», а на конкретну пару контекстів $(U_i, U_j)$, що увійшли в клінч.
2. **Точна область розбіжності:** Відомий точний перетин $U_{ij} = U_i \cap U_j$, на якому локальні твердження втратили когерентність.
3. **Обчислюваний диференціал:** Відомо значення $\delta c_{ij} = s_j|_{U_{ij}} - s_i|_{U_{ij}}$ — тобто *в чому саме* полягає несумісність.
4. **Обмежений фронт робіт:** Замість того, щоб перевіряти або генерувати всю систему заново, організм отримує математично окреслене завдання.

```text
       Контекст U_i                   Контекст U_j
   ┌───────────────────┐           ┌───────────────────┐
   │ Локальний переріз │           │ Локальний переріз │
   │       s_i         │           │       s_j         │
   └─────────┬─────────┘           └─────────┬─────────┘
             │                               │
             └───────────────┬───────────────┘
                             ▼
                    Перетин U_i ∩ U_j
                 ┌──────────────────────┐
                 │  δ c_ij = s_j - s_i  │
                 │      (H¹ ≠ 0)        │
                 └──────────┬───────────┘
                            │
               ┌────────────┴────────────┐
               ▼                         ▼
      СТАРИЙ ПІДХІД (Мінус)     НОВИЙ ПІДХІД (Плюс: Потенціал дії)
     ┌──────────────────────┐   ┌────────────────────────────────┐
     │ Veto / Смерть / Стіп │   │ Щупальце (Cohomological Probe) │
     │  REJECTED_FRACTURE   │   │ - Точковий запит на ATP        │
     │                      │   │ - Пошук контрприкладу (CEGIS)  │
     │ (статичний глухий    │   │ - Синтез локального клею       │
     │  кут)                │   │ (динамічне самозагоєння)       │
     └──────────────────────┘   └────────────────────────────────┘
```

## 4. Механізм Cohomological Probe: Від когомології до акту дослідження

Замість завершення з кодом помилки, зафіксована обструкція перетворюється на об'єкт **`CohomologicalProbe` (Когомологічна Проба)**:

```python
@dataclass(frozen=True)
class CohomologicalProbe:
    """
    Потенціал дії, породжений несклеюваним 1-коциклом Чеха.
    Не є помилкою; є формалізованим запитом на метаболічну дію.
    """
    chamber_a: str                  # U_i: Перший контекст напруги
    chamber_b: str                  # U_j: Другий контекст напруги
    intersection_domain: str        # U_ij: Межа розбіжності
    obstruction_witness: str        # δ c_ij: Диференціал розбіжності
    assigned_atp_bounty: int        # Метаболічна нагорода за розв'язання напруги
    suggested_action_type: str      # 'REFINE_COVERING' | 'DISCOVER_COUNTEREXAMPLE' | 'CEGIS_SYNTHESIS'
```

### Три траєкторії розрядки напруги (Relaxation Paths)

Коли проба випускається в міцеліальну екологію, агенти або вбудовані рушії можуть витратити свій ATP на одну з трьох канонічних дій:

1. **CEGIS Synthesis (Пошук спільного синтезу):**
   * Рушій синтезу (Engine #30, `cegis_kernel.py`) бере диференціал $\delta c_{ij}$ як предикат контрприкладу і шукає уточнений комбінаторний терм $s^*$, який одночасно редукується до $s_i$ на $U_i$ та до $s_j$ на $U_j$.
   * Якщо терм знайдено $\implies$ обструкція зникає ($\dim H^1 \to 0$), напруга спадає, глобальний переріз склеюється.

2. **Refinement of Covering (Топологічне розщеплення контекстів):**
   * Якщо синтез неможливий (твердження дійсно суперечливі в природі, як класична та квантова механіка на своїх масштабах), система визнає: покриття $\mathcal{U}$ було занадто грубим.
   * Перетин $U_{ij}$ розщеплюється на два некомутуючі листи через введення параметра граничних умов:
     $$U_{ij} \implies U_{i \setminus j} \cup U_{j \setminus i} \cup U_{\text{boundary}}$$
   * Напруга знімається не за рахунок компромісу, а за рахунок уточнення карти дійсності.

3. **Empirical Falsification (Відсікання гілки):**
   * Агент здійснює емпіричний запуск (Engine #24, DOC-F1) на тестових фікстурах.
   * Одна зі сторін конфлікту зазнає краху при реплеї. Вона отримує статус `REFUTED`, формується криптографічний надгробок (Tombstone), і хибний переріз ретирується за протоколом контрольованого забування (Engine #25, `controlled_forgetting.py`).

## 5. Чому системі більше не потрібен `while (True)`

Найбільша омана класичного штучного інтелекту — спроба надати системі «агентності» через нескінченний зовнішній цикл опитування (`while True: think()`). Це породжує галюцинації, беззмістовне спалювання ресурсів і відсутність термодинамічного спокою.

У Black-Heart потенціал дії виникає **виключно ендогенно (зсередини)**:

* Коли система узгоджена ($\dim H^1 = 0$), вона перебуває в основному квантовому стані (Ground State). Витрата ATP = 0. Система мовчить і не продукує шум. Вона стабільна століттями.
* Коли з'являється новий факт, зовнішній варант або результат вимірювання, він додається як новий локальний переріз $s_{\text{new}}$ на підпросторі $U_{\text{new}}$.
* Якщо новий факт суперечить накопиченому тілу знань, виникає $H^1 \neq 0$.
* **Саме ця обструкція миттєво генерує квант дії**: виділяється ATP, активуються сплячі проби, щупальця починають пошук контрприкладів.
* Як тільки розв'язання знайдено (синтез, розщеплення або відкидання) — $H^1$ знову падає до 0, і система повертається у кришталевий спокій.

## 7. Висновок для інженера та моделі

Не намагайтеся зробити PDF-файл одночасно універсальною математикою, мутуючим звіром, соціальною мережею і захисним інтерфейсом. Розділіть їх на лінію:
* Субстрат — нудний.
* Організм — смертний і мутуючий.
* Екологія — відкрита для спор і контрприкладів.
* Шкіра — непохитна у своїх п'яти дієсловах.

І головне: **перестаньте боятися $H^1 \neq 0$**. 
Це не вирок про несумісність. Це серцебиття системи — точка, де напруга дійсності перетворюється на чисту енергію наступного кроку.
