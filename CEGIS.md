## 1. Преамбула: Необхідність CEGIS у Black-Heart

Попередні рушії проєкту Black-Heart забезпечували аналіз, редукцію та дедуктивне доведення властивостей програм:
- `glyph.py` / `warrant_kernel.py`: Символьна редукція та виведення ордерів.
- `egraph_kernel.py`: Недеструктивна оптимізація через насичення рівностей (E-Graphs).
- `smt_kernel.py`: Першопорядковий DPLL(T) верифікатор із генерацією сертифікатів UNSAT.

Проте залишалася фундаментальна невирішена задача: **як автономно винаходити або синтезувати мінімальні, формально верифіковані комбінаторні програми із чистої специфікації поведінки?** 

Простий перебір комбінаторних дерев страждає від комбінаторного вибуху: простір виразів розміру $N$ зростає як $O(|P|^N \cdot C_N)$, де $|P|$ — кількість примітивів, а $C_N$ — числа Каталана.

`CEGIS-0.1` розв'язує цю задачу через подвійний цикл:
1. **Індуктивний синтезатор (Learner):** Генерує кандидат $P$, коректний для поточної скінченної множини прикладів $E = \{e_1, \dots, e_k\}$. Для експоненційного стиснення простору пошуку використовується **Observational Equivalence (OE)**: кандидати, що дають ідентичний вектор відповідей $\sigma(P) = \langle P(e_1), \dots, P(e_k) \rangle$, відсікаються на 99.9%.
2. **Дедуктивний верифікатор (SMT Oracle):** Формулює задачу перевірки: чи існує такий вхід $x$, для якого $P(x) \neq \text{Spec}(x)$?
   - Якщо формула **UNSAT**: кандидат $P$ математично доведено коректний для **всіх** можливих входів.
   - Якщо формула **SAT**: модель розв'язувача надає новий контрприклад $x^*$, який розширює множину $E \gets E \cup \{x^*\}$.

## 3. Нормативні Інваріанти CEGIS-0.1

### Інваріант CEGIS1: Observational Equivalence (OE) Soundness (Коректність Сигнатурного Відсікання)
Нехай $E = \{e_1, \dots, e_m\}$ — поточна множина контрприкладів. Сигнатурою програми $P$ називається кортеж значень:
$$\sigma_E(P) = \langle \text{eval}(P, e_1), \dots, \text{eval}(P, e_m) \rangle$$
Якщо для двох кандидатів $P_1$ та $P_2$ розміру $|P_1| \le |P_2|$ виконується $\sigma_E(P_1) = \sigma_E(P_2)$, кандидат $P_2$ **негайно відсікається** як семантично дублюючий на поточному базисі $E$. Це стискає простір перебору комбінаторів більш ніж на 99.9% без втрати повноти.

### Інваріант CEGIS2: Universal SMT Soundness (Універсальна Коректність Верифікації)
Вердикт `PROVED_CORRECT` може бути винесений **виключно** тоді, коли SMT-рушій `smt_kernel.py` доводить відсутність контрприкладів у всьому просторі верифікаційного домену:
$$\forall x \in \mathcal{D} : P(x) = \text{Spec}(x)$$
та генерує рефютаційний граф (UNSAT Proof DAG). Станом на 2026-09-11 цей граф проходить лише структурну перевірку `check_proof_dag_structure`: солвер записує один антецедент і не записує pivot, тож покроковий чекер `check_resolution_refutation` не приймає його як перевірену резолюційну рефютацію.

### Інваріант CEGIS3: Monotonic Basis Expansion (Монотонність Базису Контрприкладів)
У кожній ітерації $i$, якщо кандидат $P_i$ не є універсально коректним, знайдений контрприклад $x^*_i$ строго фальсифікує $P_i$:
$$P_i(x^*_i) \neq \text{Spec}(x^*_i)$$
Контрприклад додається до базису: $E_{i+1} = E_i \cup \{ (x^*_i, \text{Spec}(x^*_i)) \}$, що гарантує:
$$P_i \notin \{ P \mid \forall e \in E_{i+1} : P(e) = \text{Spec}(e) \}$$
Кандидат $P_i$ більше ніколи не буде згенерований у наступних ітераціях.

### Інваріант CEGIS4: Extensional Superoptimization Invariant (Екстенсійне Стиснення AST)
При виклику `superoptimize_combinator(expr)` синтезований комбінатор $P_{\text{opt}}$ задовольняє:
1. Екстенсійну еквівалентність: $\forall x : P_{\text{opt}} x \equiv_{\beta} \text{expr } x$.
2. Мінімальність AST: $\text{tree\_size}(P_{\text{opt}}) \le \text{tree\_size}(\text{expr})$.
3. Зменшення складності редукції (ATP Fuel).

### Інваріант CEGIS5: Epistemic Tombstone Inoculation (Карантинна Інокуляція Надгробків)
Синтезатор `BottomUpSynthesizer` індексує активні надгробки з `EpistemicTombstoneRegistry` (Engine #25). Жоден кандидат, що містить ідентифікатор або підструктуру спростованого алеля (`target_id`), не допускається до розширення в пулі кандидатів.

### Інваріант CEGIS6: ISO 32000 Vector Polyglot Physicality (Поліглотний Аудит)
Згенерований документ `cegis_synthesis.pdf` є валідним PDF згідно з ISO 32000, містить візуальний дашборд ітерацій CEGIS, таблицю історії контрприкладів і є виконуваним скриптом Python:
```bash
python3 cegis_synthesis.pdf
```
Скрипт автономно валідує SHA-256 хеш маніфесту та сертифікат SMT-рефютації. Будь-які оновлення документа через `append_cegis_hud` задовольняють інваріант апенд-онлі фізичності: `output.startswith(before) == True`.

## 4. Програмний Інтерфейс (API)

```python
import cegis_kernel
from cegis_kernel import (
    Example, BottomUpSynthesizer, CEGISLoop,
    superoptimize_combinator, generate_cegis_pdf, append_cegis_hud
)

# 1. Синтез комбінатора за поведінковою специфікацією
def boolean_not(inputs):
    # inputs[0] is Church True or False
    arg = inputs[0]
    return "b" if arg == "a" else "a"

cegis = CEGISLoop(verifier_domain=["a", "b"])
result = cegis.synthesize(boolean_not, input_arity=1)
print(f"Synthesized: {result.program_str}, Status: {result.status.value}")

# 2. Супероптимізація комбінатора
bloated = "App(App(App(S, App(K, I)), App(K, I)), x)"
opt_res = superoptimize_combinator(bloated)
print(f"Optimized: {opt_res.program_str} (Reduction: {opt_res.ast_size_reduction * 100:.1f}%)")

# 3. Експорт ISO 32000 поліглота
generate_cegis_pdf(opt_res, "cegis_opt.pdf")
```

## 5. Командний Інтерфейс (CLI)

```bash
# Синтезувати комбінатор за специфікацією (identity, constant, boolean_not)
python3 cli.py cegis synthesize --task identity

# Супероптимізувати роздутий комбінаторний вираз
python3 cli.py cegis superopt "App(App(Comb('S'), Comb('K')), Comb('K'))"

# Згенерувати ISO 32000 PDF сертифікат синтезу
python3 cli.py cegis pdf --task identity -o cegis_identity.pdf

# Запустити автономний аудит
python3 cegis_identity.pdf
```
